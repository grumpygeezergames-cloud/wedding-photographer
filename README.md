# Wedding Photographer

A charming mobile-friendly wedding photography game by GrumpyGeezer Games.

## Showcase wedding

Target gameplay: 70-second garden ceremony and 120-second reception, with six reception moments, animated guests, and a photo album.

## Publishing

Upload the latest playable HTML game as `index.html` in the repository root. Then enable GitHub Pages in **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.

The game should then be available at https://grumpygeezergames-cloud.github.io/wedding-photographer/ once Pages finishes deploying.

This repository currently contains setup documentation, not the game itself.
